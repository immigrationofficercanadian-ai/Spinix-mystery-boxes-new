# SPINIX Mystery Boxes — fresh website prototype

This is a new, standalone responsive website. It does not modify or depend on the previous website.

## Preview
Open `index.html` in a browser.

## Publish a preview with GitHub Pages
1. Create a **new** GitHub repository (do not reuse or overwrite the old one).
2. Upload `index.html`, `styles.css` and `app.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.

## Included
- Premium dark and metallic-gold branding.
- Six distinct locked metallic box designs.
- Responsive layout for phones and desktop.
- Box detail preview, My Spinix preview, FAQ, prize showcase and How it Works.
- Preview-only interactions.

## Not yet implemented
This is a front-end prototype, not a live transactional platform. It has no real authentication, database, secure admin system, payment collection, M-Pesa STK Push, Safaricom callback verification, prize inventory or auditable draw engine. The interface deliberately does not charge money or create paid entries.

Before accepting real money, obtain legal advice and the correct Kenyan regulatory licence/approval for the precise business model. Paid random-chance prize products may be regulated. Publish accurate rules, prize conditions, eligibility, odds/probabilities where required, refund and reward-fulfilment terms. Build a secure backend; never put Daraja Consumer Key, Consumer Secret or Passkey in browser code. Integrate STK Push server-side, verify callbacks and transaction status, and only mark a payment successful after server-side verification. Then obtain Safaricom production approval/credentials and test end-to-end.

Only display genuine, verified winners and testimonials, with appropriate consent. Never fabricate activity or prize claims.
